Scenario: 當在標籤管理，點擊 tag 時，以目前選擇的歷史主題，顯示所有有標示這個 tag 的事件。
  Given：已經選擇某個歷史主題，如：世界史
  When：在標籤管理點擊 tag，且有這個 tag 事件
  Then：關閉標籤管理視窗
  And: 在分類(如：傳說)右邊多加一個分隔線，顯示這個 tag 標題 與 關閉 tag 的按鈕。
  And：使用每個分區顯示被點選事件的樣式，標示有這個 tag 事件。
  And: 將每個有 tag 的事件，重要度改成 5，可以直接顯示在視窗上，不用在放大。
